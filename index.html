“신뢰와 정직을 짓는 100년 종합건설의 동반자”

안녕하십니까, 상명건설 대표이사 김상명입니다. 지난 26년간 상명건설은 사람과 공간의 조화, 원칙과 안전을 최우선 가치로 여기며 수많은 주거 및 상업 랜드마크 프로젝트를 성공적으로 완공해 왔습니다.

우리회사는 철저한 공학적 안전기준을 바탕으로 단 1건의 안전사고 없이 무사고 3,800일을 이어오고 있으며, 시공사 중심이 아닌 건축주 중심의 투명한 공정 관리와 실명 직영 시공(PM)을 통해 불필요한 마진 거품을 제거하였습니다.

처음 설계부터 준공, 그리고 2개년 무상 A/S 보증까지 건축주 여러분의 든든한 평생 파트너가 되어드릴 것을 약속드립니다. 감사합니다.

HOSTING & DEPLOYMENT GUIDE

개발서버 호스팅 추천 및 리드 가이드

비용이 적게 소요되면서 여러 프로젝트를 업로드하고 관리하기 편한 3대 호스팅 옵션 안내

1. 클라우드타입 (Cloudtype) - 가장 추천 ⭐⭐⭐⭐⭐

• 장점: 명령어 없이 GitHub 연동 또는 ZIP 업로드만으로 1분 만에 자동 배포. 프로젝트별 다중 컨테이너 생성 편리, 무료 SSL 및 주소 제공.

• 비용: 무료 체험 가능 / 월 3,000원~10,000원 수준의 최저가 플랜.

2. 카페24 가상서버(VPS) 호스팅

• 장점: 월 5,500원으로 독립 Ubuntu 서버 1대 제공. Nginx 포트 설정을 통해 10개 이상의 프로젝트를 동시 업로드 및 테스트 가능.

• 배포방법: SSH 접속 -> node.js 설치 -> 프로젝트 폴더 생성 후 pm2로 백그라운드 구동.

3. 오라클 클라우드 프리티어 (Always Free)

• 장점: 4Core 24GB 메모리 가상서버를 평생 0원(무료)으로 제공. 도커(Docker) 기반 다중 프로젝트 배포에 최적.
